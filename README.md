## 💻 Local Development

1. Clone or download the repository:
   ```bash
   git clone <YOUR_GITHUB_REPO_URL>
   cd ansari-aluminium
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start development server:
   ```bash
   npm run dev
   ```
   Open `http://localhost:3000` in your browser.

4. Build for production:
   ```bash
   npm run build
   ```
   Production files will be generated in the `dist/` directory.

## 🌐 Deploy to Netlify

Yeh project Netlify par deploy karne ke liye pehle se hi configure hai:

1. **Option A (GitHub Link)**:
   - Apne GitHub account se repo connect karein.
   - Netlify `netlify.toml` ko automatically read karega:
     - **Build Command**: `npm run build`
     - **Publish Directory**: `dist`
2. **Option B (Drag & Drop)**:
   - `npm run build` chala kar `dist` folder ko [app.netlify.com/drop](https://app.netlify.com/drop) par drop kar dein.
